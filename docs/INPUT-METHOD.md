# 手柄输入法（柄输 Binput 融合版）

> 适用于 V0.8.80 及以后。入口：工作台 →「手柄输入法」。
>
> 原作：莫古雨 · [Binput](https://github.com/moguyu-binput/Binput) 2.5.0 · GPL-3.0。
> 本程序在 GPL-3.0 下分发，源码随项目提供（`src\LeadjoyBlade.Binput\`）。

---

## 1. 这是什么

把手柄当键盘用的中文输入法：九宫格拼音 / 全键盘英文，用手柄选键，由系统输入法出汉字。
本版本已经把 Binput 的**源码整体编进风刃手柄助手**，不是外挂一个 exe：

- 不需要另装 .NET 8 桌面运行时（跟随主程序 self-contained 发布）；
- 不需要单独启动「柄输.exe」，也没有第二个托盘图标；
- 词库、皮肤、图标全部内嵌在程序里，单文件 exe 不会漏文件；
- 不再引用任何 NuGet 包（DPAPI 改为直接调用系统 `crypt32`）。

---

## 2. 启用 / 停用

1. 打开工作台 →「手柄输入法」，打开右上角「启用」开关。
2. 启用后，按手柄 **L3 + R3** 随时唤出 / 收起悬浮键盘。
3. 停用：关掉同一个开关；或在悬浮键盘背面设置里点「停用」。

托盘右键 →「手柄输入法」也有：

- 显示 / 隐藏键盘
- 输入法设置…
- 启用 / 停用

> 启用状态保存在 `save\Binput.save`，下次启动主程序会自动恢复。
>
> **V0.8.47 起**：启用只表示“热键可以唤醒”。键盘收起时完全不查询/改写系统输入法，
> Ctrl+Space 等正常输入不受影响；直出版也不会在后台轮询目标窗口的 IME。

## 3. 两种输入模式

| 模式 | 界面 | 字去哪儿 | 适合 |
|---|---|---|---|
| **预输入版**（推荐） | 前台窗口 + 预览框 | 先打进预览框，收起时整段复制 + 粘贴 | FF14 等游戏，不会吃到半截按键 |
| **直出版** | 不抢焦点、没有预览框 | 按键直接送到当前有焦点的窗口 | 普通 Windows 窗口 |

切换方式：工作台页面「输入设置 → 输入模式」，或悬浮键盘背面设置 →「版本」。

**中英文怎么切**：

- **手柄 Y 键**：九键（中文拼音）↔ 全键盘（纯英文）。有拼音待发时 Y 是“切分”，先按 RB 发出去或 X 删掉再切。
- 九键要靠系统输入法出汉字；Binput 在切布局时会尝试把系统输入法切到中文（全键盘则切英文）。
- **直出版**不抢焦点，也不会在后台持续切目标窗口的输入法；九键打中文前，目标窗口需要先处于中文输入法（可用 Ctrl+Space）。游戏里建议用预输入版。

**按配置保存（V0.8.56）**：输入法开关、输入模式、唤醒键都存在当前配置里；
「设置 → 配置管理」也有「本配置启用手柄输入法」。切换配置会自动启动/停止并应用该配置的设置。
如果唤醒键与按键映射或幻想模式基础键冲突，输入法页会显示黄色提示；
**幻想模式启用时按键映射/组合键已经不可用，不再提示与它们的冲突，只检查幻想基础键和系统菜单呼出键**。
与幻想基础键同键时（例如 L3），该基础键会置灰并在运行时停止映射。

### 3.1 悬浮窗大小、透明度、锁定与拖动（V0.8.65）

- 工作台「手柄输入法 → 输入设置 → 悬浮窗大小」可调 **60%~180%**，拖动滑块时实时生效，
  松手约 350ms 后写入 `save\Binput.save`，下次启动恢复。
- 同一页的「悬浮窗透明度」可调 **20%~100%**，同样实时生效并记忆。
- 悬浮窗**左下角小锁**默认锁住；点一下开锁，锁梁以右梁柱为纵轴水平镜像翻转，左梁柱翻到锁体外侧（锁体不位移），
  顶部出现**胶囊形**「⠿ 拖动悬浮窗」拖动条，按住即可移动整个悬浮窗。
- 多屏时可直接拖到任意显示器（按整个虚拟桌面边界，不再只限主屏）。
- 拖动松手即记住位置；收起再唤出、重启主程序后仍在原位置。
- 再点小锁可重新锁住，拖动条隐藏，避免误拖；位置、大小、透明度都不会丢。

## 4. 手柄键位

| 键 | 作用 |
|---|---|
| **L3 + R3** | 唤出 / 收起（可改，见下） |
| 左摇杆 | 在九宫格 / 全键盘上选键 |
| A | 输入光标所在的键 |
| X | 退格 |
| RT | 回车 |
| **RB** | 发出拼音；没有待发拼音时是空格 |
| 十字键 ← → | 挑拼音切分；发出拼音后是方向键；↑ / ↓ 翻页 |
| Y（有拼音） | 只定住头一个字 |
| Y（没拼音） | 单击：九键 ↔ 全键盘；长按约 0.5 秒：进 / 出设置 |
| LT（按住） | 数字层 |
| LB（按住） | 滑行输入（左摇杆推方向） |
| 悬浮键盘右下角齿轮 | 翻到设置面（也可长按 Y） |

**选格范围（V0.8.47）**：九键的斜角格要 **两个轴都超过 0.35** 才算斜方向；
原来的格子边界是 1/3，只多出 0.017，所以轻轻推过格子边界就会换格，同时正方向推歪一点也不会掉进斜格。
选格直接跟手，没有额外防抖延迟。

**摇杆死区（V0.8.49）**：输入法每 500ms 同步「设置 → 摇杆与扳机」里的
**左右摇杆死区**。死区以内不会选中九宫格，也不会触发右摇杆标点层；
调完滑块稍等半秒生效。

**全键盘 LB（V0.8.52）**：全键盘下按住 LB = Shift，保持到大写松开；
直连通道在 BLE 低上报时有 10s 宽限，不会 500ms 就掉回原生通道把 LB 状态丢掉。

**右摇杆标点（V0.8.47）**：

- 推到某一格停约 **0.18 秒**，输入该格标点；
- **摇杆不回中**、直接选另一个标点时，会把刚才那个标点退格替换成新标点；
- **不会按住连续输出**同一标点；摇杆回中即确认当前标点；
- 九键标点层的「、」已换成「+」。

唤醒键可在工作台页面改成：`L3 + R3`（默认）/ `Back` / `Start` / `Back + Start` / `L3` / `R3`，
或键盘 `F1`~`F12`。键盘唤醒键只“顺带”监听，不吞键、不抢游戏按键。

## 5. 完整设置

点工作台页面的「输入法设置」，或悬浮键盘右下角的齿轮，会把键盘翻到背面：

- 版本（预输入 / 直出、收起后的粘贴档位）
- 主题 / 皮肤（含「可爱粉」贴纸皮肤）
- 键盘（九键数字、按键形状、JKL 位置、方阵 / 轮盘、九键 / 双拼、快捷短语）
- 滑行输入（触发 / 连发判定）
- 动效
- 维护（输入习惯、日志、导入导出）
- 停用
- 唤醒键

「调整键盘大小 / 位置」：十字键上下缩放，左摇杆挪位置，按 B 退出并保存。

## 6. 手柄通道：风刃直连优先

这是融合版和原版最大的一处改动。

| 情况 | 输入法听谁的 |
|---|---|
| 风刃已连接手柄 | 用风刃 `BladeReport` 解析出的状态（BLE 1B / Switch / DS4 / XInput / RawGameController 都行） |
| 风刃未连接 | 回退到 Binput 原生的 XInput / `Windows.Gaming.Input` / HID 三条通道 |

实现：`App.Devices.ReportReceived` → `BinputHost.FeedPad()` → `PadBus` 直连通道（500ms 无新帧自动回退）。
因此即使手柄工作在厂商标有 `Blade Plus_1B` 的私有 BLE 模式，也能用来打字。

---

## 7. 和风刃映射的关系

- 输入法**唤出期间**，风刃的按键映射 / 幻想模式自动暂停，避免按 A 选键同时触发映射；
- 输入法收起后自动恢复，不需要手动切换映射开关；
- 输入法未启用时，不占用任何手柄轮询；
- **手柄关机/断联时**，风刃映射和幻想模式都会立即释放摇杆鼠标、按键和直连通道，250ms 无新报文还会兜底归位，不会让鼠标一直往左上跑。

> L3 + R3 按下的那一帧仍会先经过映射（此时输入法还没“唤出”）。如果某个配置把
> L3 / R3 映射成了动作，唤醒时可能顺带触发一次；需要的话把这两个键留空即可。

## 9. 常见问题

1. **按 L3 + R3 没反应**
   - 确认页面显示「运行中」，手柄通道不是「未检测到手柄」；
   - 确认手柄没有被其他程序独占；换 USB 线 / 重连试试；
   - 看 `save\log.txt` 里有没有「唤醒键（手柄）」这一行。

2. **游戏里打不出字**
   - 游戏以管理员身份运行时，本程序也要以管理员身份运行（UIPI 会静默丢弃低权限按键）；
   - 先用记事本测试：能出字说明注入正常，是游戏反作弊 / 独占输入的问题；
   - 预输入版会自动尝试把系统输入法切成中文；切不过去时手动按一次 Shift / Ctrl+Space。

3. **悬浮键盘被游戏盖住**
   - 独占全屏游戏可能盖住 Topmost 窗口，改成无边框窗口化即可。

4. **想让中文候选框更稳**
   - 用预输入版；它会把键盘窗口顶到前台，系统输入法候选窗才能正常显示。

5. **不再需要这个功能**
   - 工作台关掉「启用」，或输入法设置 →「停用」；不会影响风刃映射。

6. **开启输入法后 Ctrl+Space 切不了中文（V0.8.47 已修）**
   - 原因：旧版每 250ms 查询一次前台窗口的 IME 上下文，跨线程 `ImmGetContext` / `ImmReleaseContext` 会干扰系统输入法；
   - V0.8.47 起：键盘收起时不再查询/改写 IME，直出版也不轮询目标窗口；Ctrl+Space 恢复正常；
   - 若仍遇到，确认版本是 V0.8.47，并先按热键把悬浮键盘收起再试。

7. **唤醒后自动翻到标点页 / 持续输出标点（V0.8.47 已修）**
   - 多见于非 Sony VID 的 DS4 兼容手柄：旧版按 Xbox 轴序读，静息 `axes[3]=0` 被当成右摇杆推到底；
   - V0.8.47 起按系统标签（Square / Cross / Triangle / Left1）识别 DS 布局，右摇杆读 0；
   - 可在 `logs\hiddle.log` 查「轴布局：DS4/PlayStation」确认。

8. **左摇杆选格上下颠倒 / 推正方向偶尔跳斜方向（V0.8.47 已修）**
   - DS4 原生轴路径补上了 Y 反相（HID 原始 0=上 → Binput 的 +Y=上）；
   - 斜角要两个轴都超过 0.35 才算斜方向，正方向略大；只比原 1/3 多 0.017，轻推过格子边界就会换格；
   - 如果仍然上下颠倒，可能是手柄固件方向相反，请反馈 `logs\hiddle.log` 的轴值。

9. **手柄关机/断联后鼠标一直往左上跑（V0.8.48 已修）**
   - 断联时立即 `MappingEngine.OnDisconnected()` + `FantasyRuntime.Suspend()`，释放摇杆鼠标、按键和直连通道；
   - 两个引擎的鼠标定时器都有 **250ms 无报文兜底**，即使没收到断联事件也会归位；
   - 仍残留时重新开手柄并重连。

10. **摇杆死区对输入法无效（V0.8.49 已修）**
   - 旧版输入法用写死的 0.2747 死区，不跟随「摇杆与扳机」里的设置；
   - V0.8.49 起每 500ms 同步左右摇杆死区；死区内不选格、不触发右摇杆标点。

11. **左右摇杆映射断断续续、LB 不能连发（V0.8.50 已修）**
   - V0.8.48 的 250ms 无报文兜底会在 BLE 1B 低上报（日志常见 0.25~2s 间隔）时反复 `ReleaseAll`，
     把按住/连发打断；
   - V0.8.50 起无报文只停摇杆鼠标，不释放按键/连发；真正断联仍由断联事件立即释放。

12. **全键盘按住 LB 大写一下又变回小写（V0.8.52 已修）**
   - 直连通道原来 500ms 没新报文就回退原生三条路，BLE 稀疏时 LB 状态丢失；
   - V0.8.52 起直连保持 10s，真正断联由 `FeedPadDisconnected` 立即切走；LB 按住期间一直大写。

## 10. 维护者备注（源码结构）

| 位置 | 内容 |
|---|---|
| `src\LeadjoyBlade.Binput\` | Binput 2.5.0 源码整体迁入，命名空间 `LeadjoyBlade.Binput` |
| `BinputHost.cs` | 原 `App.xaml.cs` 改成可嵌入宿主：`Start/Stop/ShowKeyboard/OpenSettings/FeedPad` |
| `OverlayWindow.*` | 悬浮键盘与设置面（9 个 partial，未改逻辑） |
| `InputCore.cs` / `T9Engine.cs` | 输入逻辑 / 拼音切分（未改逻辑） |
| `PadBus.cs` | 新增 `Feed()` 直连通道 |
| `Config.cs` | DPAPI 改 P/Invoke；新增 `LoadEnabled/SaveEnabled` |
| `SkinTex.cs` | 外部 `skin\` 缺失时读程序集内嵌图 |
| `BinputHost.LoadDict()` | 外部 `dict.txt` 缺失时读内嵌词库 |
| `Views\GamepadImePage.xaml(.cs)` | 工作台标签页：启用、状态、模式、唤醒键、说明、数据入口 |

注意事项：

- 主程序 `App.xaml` 有大量隐式样式（TextBlock / TextBox / ScrollViewer…），会漏进悬浮窗；
  `OverlayWindow.xaml` 的 `Window.Resources` 里给同名类型放了空样式做隔离，不要删。
- 单文件发布时资源走 `pack://application:,,,/LeadjoyBlade.Binput;component/...`；
  新增素材时记得在 `LeadjoyBlade.Binput.csproj` 里设为 `Resource`。
- 不再给这个项目加 NuGet 包；需要系统 API 就 P/Invoke。
